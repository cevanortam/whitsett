This tab and the Inbound tab share the same SAP export — uploading a file here (or on the Inbound tab) updates both automatically, since the export contains both picking and receiving/putaway activity together. Repeat uploads merge into existing data and are de-duplicated by Warehouse Task, so re-uploading an export that overlaps a previous one is safe. On the Executive Summary, every KPI popup (Fill Rate, Dock to Stock, On-Time Delivery Auto/Manual, Inventory Accuracy) offers the same "✎ Omit" control per row — click it, give a required reason (e.g. a customer-requested overpick held as reserve stock, or a delay outside the warehouse's control), and that row stops counting as a breach/miss for that metric. The row stays visible in the popup and Excel export either way, marked "Omitted," and can be un-omitted at any time from the same spot. Dock to Stock and On-Time Delivery omissions write to the same override data as the Inbound/Outbound tabs' own "Override" buttons, so they stay in sync; Inventory Accuracy omissions are tracked separately since that metric has no override elsewhere.

Each row is a bin/product location, resolved from every Physical Inventory Document on file for that Storage Bin + Product. If a recount was generated (status RECO) and its linked recount document (status COUN) matched book qty, the location is marked Accurate — the recount is what counts, not the original miss. A location only shows Inaccurate once it has a completed count (COUN) with no Active (ACTI) recount still pending against it. Locations with an Active count outstanding are Open and excluded from the accuracy figures until resolved. "Location Accuracy" on the Executive Summary rolls this up one level further: a Storage Bin counts as accurate only if every product resolved there was accurate. This is a separate data source from the Outbound/Inbound SAP export — upload the cycle count results file here. Repeat uploads merge into existing data and are de-duplicated by Physical Inventory Document, so re-uploading an export that overlaps a previous one is safe. The Day/Week/Month/ Year and date-range controls above filter strictly to that window — both the table and every KPI/chart on this tab, including Open/Recount Pending locations dated outside the window. The Open Counts and Oldest Open Count cards are the one exception: they always reflect the live, all-time backlog regardless of the range selected, since that backlog needs attention no matter when it was assigned. Priced Net/Gross inventory value reporting now lives on the standalone Inventory Reconciliation dashboard, which reads this same cycle count data.
