Each row is a bin/product location, resolved from every Physical Inventory Document on file for that Storage Bin + Product. If a recount was generated (status RECO) and its linked recount document (status COUN) matched book qty, the location is marked Accurate — the recount is what counts, not the original miss. A location only shows Inaccurate once it has a completed count (COUN) with no Active (ACTI) recount still pending against it. Locations with an Active count outstanding are Open and excluded from the accuracy figures until resolved. "Location Accuracy" on the Executive Summary rolls this up one level further: a Storage Bin counts as accurate only if every product resolved there was accurate. This is a separate data source from the Outbound/Inbound SAP export — upload the cycle count results file here. Repeat uploads merge into existing data and are de-duplicated by Physical Inventory Document, so re-uploading an export that overlaps a previous one is safe.
